NEXEN Backup Manager

Proteção responsável dos dados de cada negócio.

O NEXEN Backup Manager é uma ferramenta interna de automação de cópias de segurança de sistemas de gestão. Ela foi concebida para apoiar a continuidade operacional e a recuperação de dados de estabelecimentos atendidos.

Como funciona

Mediante autorização da conta responsável, a ferramenta utiliza a Google Drive API com permissão limitada drive.file para armazenar e conferir arquivos de backup criptografados. Não é um serviço de armazenamento aberto ao público.
